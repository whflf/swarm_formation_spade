# Swarm Formation SPADE

Мультиагентная система управления роем роботов: алгоритм **SPSA-консенсуса** для оценки взаимных позиций + **LVP-контроллер** для построения квадратной формации.

Агенты реализованы на фреймворке [SPADE](https://spade-mas.readthedocs.io/) и общаются через XMPP. Физика роботов (зашумлённые расстояния UWB, пеленги STM32, меканум-колёса) эмулируется симулятором.

---

## Описание задачи

Четыре робота с меканум-колёсами должны выстроиться в квадрат со стороной 2 м. Каждый робот:

- знает **только зашумлённые расстояния** до соседей (датчик DW3000, шум ≈ 0.5 м)
- знает **зашумлённые пеленги** на соседей (датчик STM32, шум ≈ 0.05 рад)
- **не знает** своё абсолютное положение в мировой системе координат
- общается с соседями по **полному графу K4** через XMPP

Задача решается в два этапа:

| Фаза | Итерации | Что происходит |
|------|----------|----------------|
| **Warmup** | 8 000 | SPSA-консенсус: каждый агент строит локальную карту позиций соседей |
| **Управление** | 300 тиков | LVP-контроллер двигает рой в формацию; одновременно продолжается SPSA (80 шагов/тик) |

## Архитектура

```
swarm_formation_spade/
├── config.py                  # все гиперпараметры системы
├── main.py                    # точка входа: SPADE + встроенный XMPP
├── spsa_formation_agent.py    # класс SPSAFormationAgent и его Behaviour
├── robot_swarm_simulator.py   # физический симулятор (позиции, шум, управление)
└── validate_formation.py      # синхронная проверка алгоритмов без XMPP
```

## Установка

Python 3.7+. Рекомендуется виртуальное окружение.

```bash

pip install numpy scipy spade
```

> Встроенный XMPP-сервер входит в пакет `spade` — отдельный Prosody/Ejabberd не нужен.

## Метрики

| Метрика | Описание |
|---------|----------|
| `dist_res` | Средняя абсолютная ошибка между оценёнными и истинными расстояниями до соседей (м) |
| `form_err` | Средняя абсолютная ошибка между целевыми попарными расстояниями квадрата и реальными (м) |
| `scale` | Коэффициент масштаба, только в `validate_formation.py` |

## Конфигурация (config.py)

### Сеть агентов

| Параметр | Значение | Описание |
|----------|----------|----------|
| `N` | 4 | Число роботов |
| `NEIGHBORS` | K4 | Полный граф: каждый видит всех остальных |
| `AGENTS_CREDENTIALS` | agent0–3@localhost | JID и пароли для XMPP |

### Фазы выполнения

| Параметр | Значение | Описание |
|----------|----------|----------|
| `WARMUP_ITERS` | 8000 | Итераций чистого SPSA (рой стоит) |
| `CONTROL_ITERS` | 300 | Тиков управления после прогрева |
| `SPSA_PER_TICK` | 80 | Шагов SPSA внутри одного тика |
| `PERIOD` | 0.01 с | Период PeriodicBehaviour агента |

### Алгоритм SPSA

| Параметр | Значение | Описание |
|----------|----------|----------|
| `ALPHA` | 0.001 | Начальный размер шага |
| `ALPHA_DECAY` | 0.975 | Множитель затухания шага |
| `BETA` | 1.0 | Начальный размер возмущения |
| `BETA_DECAY` | 1.025 | Множитель роста возмущения |
| `GAMMA` | 0.4 | Коэффициент консенсуса |
| `N_GRADIENT_SAMPLES` | 5 | Выборок для оценки градиента |

### Датчики и среда

| Параметр | Значение | Описание                                   |
|----------|----------|--------------------------------------------|
| `NOISE_SCALE` | 0.5 м | Амплитуда шума UWB (DW3000)                |
| `BEARING_NOISE` | 0.05 рад | Шум пеленга (STM32)                        |
| `AREA_SIZE` | 10.0 м | Размер области для случайной инициализации |
| `SEED` | 7 | Для генератора случайных чисел             |

### Управление

| Параметр | Значение | Описание |
|----------|----------|----------|
| `FORMATION_SIDE` | 2.0 м | Сторона квадратной формации |
| `GAMMA_LVP` | 0.08 | Коэффициент усиления LVP-контроллера |
| `SPEED_LIMIT` | 0.02 м/тик | Ограничение скорости робота |

### Внешнее воздействие (JOYSTICK)

Функция `JOYSTICK(tick)` задаёт скорость рою извне для проверки устойчивости формации:

```
тики  0–49:    покой        [0.00,  0.00] м/тик
тики 50–119:   вправо       [0.02,  0.00] м/тик
тики 120–199:  вправо+вверх [0.01,  0.02] м/тик
тики 200–249:  влево        [-0.02, 0.00] м/тик
тики 250+:     покой        [0.00,  0.00] м/тик
```

## Структура сообщений XMPP

Агенты обмениваются JSON:

```json
{
  "from": 0,
  "iter": 1234,
  "theta": {"0": [5.1, 6.7], "1": [7.2, 6.8], "2": [7.1, 4.9], "3": [5.0, 4.7]},
  "dist":  {"1": 2.03, "2": 2.84, "3": 2.01}
}
```

- `theta` — текущие оценки позиций всех роботов
- `dist` — зашумлённые расстояния до соседей (для консенсуса по измерениям)
