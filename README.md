# Swarm Formation SPADE

[![CI](https://github.com/whflf/swarm_formation_spade/actions/workflows/ci.yml/badge.svg)](https://github.com/whflf/swarm_formation_spade/actions/workflows/ci.yml)
[![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)

Мультиагентная система управления роем роботов: алгоритм **SPSA-консенсуса** для оценки взаимных позиций и **гибридный LVP-контроллер** для построения формации.

Агенты реализованы на фреймворке [SPADE](https://spade-mas.readthedocs.io/) и общаются через XMPP. Физика роботов (зашумлённые расстояния UWB, пеленги STM32, меканум-колёса) эмулируется симулятором.

---

## Задача

Четыре робота с меканум-колёсами должны выстроиться в квадрат со стороной 2 м. Каждый робот:

- знает **только зашумлённые расстояния** до соседей (датчик DW3000, шум ≈ 0.5 м)
- знает **зашумлённые пеленги** на соседей (датчик STM32, шум ≈ 0.05 рад)
- **не знает** своё абсолютное положение в мировой системе координат
- общается с соседями по **полному графу K4** через XMPP

Задача решается в два этапа:

| Фаза | Итерации | Что происходит |
|------|----------|----------------|
| **Warmup** | 8 000 | SPSA-консенсус: каждый агент строит локальную карту позиций соседей |
| **Управление** | 300 тиков | LVP-контроллер двигает рой в формацию; SPSA продолжается (80 шагов/тик) |

### Ключевые идеи реализации

**Гибридный LVP:** направление `n_ij` берётся из медленно меняющейся карты SPSA (сохраняет хиральность), а величина ошибки `(d_meas − d*)` — из свежего замера дальномера. Это разрывает цепочку «движение → деградация карты → деградация управления».

**Коррекция хиральности:** карта из попарных расстояний неоднозначна (зеркальное отражение даёт те же расстояния). Пеленги STM32 определяют знак ориентации через знак векторного произведения. Логика вынесена в публичную функцию `detect_map_reflection(theta, bearings, self_idx)`.

**Распределённый heading:** робот 0 оценивает курс через карту SPSA; роботы 1..N-1 — через пеленги относительно робота 0.

## Установка

Требуется Python 3.10+. Рекомендуется виртуальное окружение.

```bash
pip install numpy scipy spade
```

> Встроенный XMPP-сервер входит в пакет `spade` — отдельный Prosody/Ejabberd не нужен.

Для разработки (линтер + тесты):

```bash
pip install -e ".[dev]"
```

## Запуск

### Полная мультиагентная система

```bash
python main.py
```

Запускает встроенный XMPP-сервер, регистрирует 4 агента и выполняет обе фазы.

**Пример вывода:**

```
============================================================
Рой: 4 роботов, квадрат 2.0x2.0 м, seed=7
Warmup: 8000 iter  |  Управление: 300 тиков
============================================================
  [warmup] iter= 1000  dist_res=1.847 м
  [warmup] iter= 2000  dist_res=1.203 м
  ...
  [warmup] iter= 8000  dist_res=0.218 м

Warmup завершён. Назначение (агент 0): {0: 0, 1: 1, 2: 2, 3: 3}

  тик |   form_err |   dist_res
--------------------------------
    0  |      2.341 м |      0.218 м
   50  |      1.876 м |      0.201 м
  ...
  300  |      0.487 м |      0.161 м

============================================================
ИТОГ:  form_err=0.487 м   dist_res=0.161 м
```

### Синхронная валидация (без XMPP)

Воспроизводит те же вычисления без накладных расходов на асинхронность:

```bash
python validation/validate_formation.py
```

**Пример вывода:**

```
==================================================
ИТОГ (seed=7):
  form_err min  = 0.481 м
  form_err tail = 0.489 м
  dist_res      = 0.161 м
  scale         = 0.997
```

Поле `scale` — Procrustes-масштаб карты относительно реальных позиций (1.0 = идеально).

### Эксперименты с формациями

```bash
# 6 роботов, правильный шестиугольник
python experiments/test_formations.py --n 6 --seed 7 --formation polygon

# 8 роботов, прямоугольная сетка
python experiments/test_formations.py --n 8 --formation grid --warmup 6000

# Доступные формации: polygon, line, grid, vshape
```

### Тест масштабируемости

```bash
# 20 роботов, полный прогон
python experiments/test_scale_fast.py --n 20 --seed 7

# Быстрая проверка
python experiments/test_scale_fast.py --n 4 --seed 7 --warmup 200 --ctrl 5
```

### Тесты

```bash
pytest
```

41 тест покрывает геометрию формаций (`make_formation_polygon`), детекцию хиральности (`detect_map_reflection`) и физический симулятор (`RobotSwarmSimulator`).

## Метрики

| Метрика | Описание |
|---------|----------|
| `dist_res` | Средняя абсолютная ошибка оценённых расстояний относительно истинных (м) |
| `form_err` | Средняя абсолютная ошибка попарных расстояний между целевой и реальной формацией (м) |
| `scale` | Procrustes-масштаб карты (1.0 = идеально; только `validate_formation.py`) |

## Конфигурация (`swarm/config.py`)

### Сеть агентов

| Параметр | Значение | Описание |
|----------|----------|----------|
| `N` | 4 | Число роботов |
| `NEIGHBORS` | K4 | Полный граф: каждый видит всех остальных |
| `AGENTS_CREDENTIALS` | agent0–3@localhost | JID и пароли для XMPP |

### Фазы выполнения

| Параметр | Значение | Описание |
|----------|----------|----------|
| `WARMUP_ITERS` | 8000 | Итераций чистого SPSA (рой стоит) |
| `CONTROL_ITERS` | 300 | Тиков управления после прогрева |
| `SPSA_PER_TICK` | 80 | Шагов SPSA внутри одного тика |
| `PERIOD` | 0.01 с | Период PeriodicBehaviour агента |

### Алгоритм SPSA

| Параметр | Значение | Описание |
|----------|----------|----------|
| `ALPHA` | 0.001 | Начальный размер шага |
| `ALPHA_DECAY` | 0.975 | Множитель затухания шага |
| `BETA` | 1.0 | Начальный размер возмущения |
| `BETA_DECAY` | 1.025 | Множитель роста возмущения |
| `GAMMA` | 0.4 | Коэффициент консенсуса |
| `N_GRADIENT_SAMPLES` | 5 | Выборок для оценки градиента |

### Датчики и среда

| Параметр | Значение | Описание |
|----------|----------|----------|
| `NOISE_SCALE` | 0.5 м | Амплитуда шума UWB (DW3000) |
| `BEARING_NOISE` | 0.05 рад | Шум пеленга (STM32) |
| `AREA_SIZE` | 10.0 м | Размер области для случайной инициализации |
| `SEED` | 7 | Зерно генератора случайных чисел |

### Управление

| Параметр | Значение | Описание |
|----------|----------|----------|
| `FORMATION_SIDE` | 2.0 м | Сторона целевого квадрата |
| `GAMMA_LVP` | 0.08 | Коэффициент усиления LVP-контроллера |
| `SPEED_LIMIT` | 0.02 м/тик | Ограничение скорости робота |

### Внешнее воздействие (`joystick`)

Функция `joystick(tick)` задаёт скорость рою извне для проверки устойчивости формации:

```
тики   0–49:   покой        [0.00,  0.00] м/тик
тики  50–119:  вправо       [0.02,  0.00] м/тик
тики 120–199:  вправо+вверх [0.01,  0.02] м/тик
тики 200–249:  влево        [-0.02, 0.00] м/тик
тики 250+:     покой        [0.00,  0.00] м/тик
```

## Формат сообщений XMPP

Агенты обмениваются JSON:

```json
{
  "from_idx": 0,
  "iter": 1234,
  "theta": {"0": [5.1, 6.7], "1": [7.2, 6.8], "2": [7.1, 4.9], "3": [5.0, 4.7]},
  "dist":  {"1": 2.03, "2": 2.84, "3": 2.01}
}
```

- `theta` — текущие оценки позиций всех роботов в локальной системе координат агента
- `dist` — зашумлённые расстояния до активных соседей (используются в консенсусе)
